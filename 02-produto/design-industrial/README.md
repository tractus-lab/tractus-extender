# Design industrial

Aqui ficam sketches, moodboards, renders, modelos CAD e estudos de forma.

## Organização sugerida
- `sketches/` — desenhos à mão, fotos de rascunhos
- `moodboard/` — referências visuais, cores, texturas, produtos admirados
- `cad/` — arquivos 3D (STEP, STL, Fusion, SolidWorks, FreeCAD)
- `renders/` — imagens finais para apresentação

## Princípios de design do produto
Defina 3 a 5 palavras que descrevem como o produto deve parecer e se sentir (ex.: robusto, discreto, acolhedor, preciso). Toda decisão de forma deve respeitar isso.

## Decisões de forma e material
Registre em `decisoes/` as escolhas que não são óbvias.
