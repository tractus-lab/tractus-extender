# Protótipos

Cada protótipo ganha uma pasta: `P01-nome-curto/`, `P02-...`.

## Em cada pasta
- `objetivo.md` — o que esse protótipo quer provar ou testar
- fotos e vídeos
- `resultados.md` — o que funcionou, o que não, o que muda no próximo

## Tipos de protótipo
1. **De aparência:** só a forma, sem função. Papelão, impressão 3D, espuma. Serve para testar ergonomia e reação das pessoas.
2. **Funcional:** só a função, sem forma. Placa de ensaio, peças soltas. Serve para provar que a tecnologia funciona.
3. **Integrado:** forma + função. Próximo do produto final.
4. **Lote piloto:** feito com o processo real de fabricação, em pequena quantidade.
