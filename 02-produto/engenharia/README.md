# Engenharia

Esquemáticos, layouts de placa, cálculos, diagramas de blocos, firmware, desenhos mecânicos técnicos.

## Organização sugerida
- `eletronica/` — esquemáticos (KiCad, EasyEDA), layout, lista de componentes
- `mecanica/` — desenhos técnicos com cotas e tolerâncias
- `firmware/` — código embarcado
- `calculos/` — planilhas e memórias de cálculo (térmico, estrutural, autonomia)
- `testes/` — procedimentos e resultados de testes
