# Glossário

Termos e siglas usados no projeto. Adicione conforme aparecerem.

| Termo | Significado |
|---|---|
| BOM | Bill of Materials. Lista de materiais e componentes do produto, com quantidades e custos. |
| PRD | Product Requirements Document. Documento de requisitos do produto. |
| MVP | Produto mínimo viável. Versão mais simples que já resolve o problema principal. |
| CAD | Desenho assistido por computador. Modelos 3D do produto. |
| DFM | Design for Manufacturing. Projetar pensando em como será fabricado. |
| INPI | Instituto Nacional da Propriedade Industrial. Registro de marcas, patentes e desenho industrial no Brasil. |
| INMETRO | Instituto Nacional de Metrologia, Qualidade e Tecnologia. Certificação compulsória de vários produtos físicos. |
| ANATEL | Agência Nacional de Telecomunicações. Homologação obrigatória para produtos com rádio (Wi-Fi, Bluetooth, etc.). |
| ANVISA | Agência Nacional de Vigilância Sanitária. Regula produtos de saúde, cosméticos, alimentos. |
| NCM | Nomenclatura Comum do Mercosul. Código que classifica o produto para fins fiscais e de importação. |
| MEI | Microempreendedor Individual. Faturamento limitado, não permite sócios. |
| LTDA | Sociedade Limitada. Tipo jurídico mais comum para pequenas empresas com ou sem sócios (SLU para sócio único). |
| Simples Nacional | Regime tributário simplificado para micro e pequenas empresas. |
| CNAE | Classificação Nacional de Atividades Econômicas. Define a atividade da empresa. |

## Mecânica (hastes do extensor)

| Termo | Significado |
|---|---|
| Barra roscada / haste roscada | Nome comercial da barra de metal com rosca ao longo de todo o comprimento (ex.: "barra roscada M6 inox 304"). É a haste das pernas do extensor. |
| Fuso | Nome de engenharia da barra roscada quando a função é transformar giro em deslocamento linear. |
| Porca / castanha | Peça com rosca interna que gira sobre o fuso e avança. No extensor, o punho serrilhado faz esse papel. "Fuso e castanha" é o par clássico (morsa, macaco, impressora 3D). |
| Passo | Avanço por volta. Rosca M6 padrão: 1 mm por volta. |
| Rosca métrica (M6, M8) | Perfil de rosca comum; o número é o diâmetro externo em mm. |
| Rosca trapezoidal (Tr8x2) | Perfil mais robusto para fusos de carga; usado em impressoras 3D. Mais caro e grosso do que o necessário aqui. |
| Contraporca | Segunda porca apertada contra outra peça para travar a posição (as porcas pretas junto ao tambor e à barra do Epic). |
| Inox 304 | Aço inoxidável comum para peças em contato com a pele e umidade; não enferruja em uso normal. |
| Pivô / tambor | Cilindro de inox alojado num rasgo da base, onde a haste rosqueia. Gira em torno de um pino transversal (cabeça escondida por uma tampa redonda de plástico na face externa do lobo) para mudar o ângulo base–haste. |
| Ponte | Plataforma única entre as duas hastes, no topo dos tubos da escala, com um rebaixo circular aberto de um lado onde o pescoço do copo encaixa. |
