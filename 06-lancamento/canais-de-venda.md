# Canais de venda

Escopo: Brasil. Todos os canais abaixo são nacionais.

| Canal | Vantagem | Desvantagem | Comissão / custo | Prioridade |
|---|---|---|---|---|
| Loja própria (Shopify, Nuvemshop, Loja Integrada) | Margem, dados do cliente, marca | Precisa trazer tráfego | Mensalidade + taxa de pagamento | |
| Mercado Livre | Maior audiência do Brasil | Comissão alta, guerra de preço | 11–19% | |
| Amazon Brasil | Credibilidade, FBA | Comissão, concorrência | ~15% | |
| Shopee | Volume, público jovem | Preço baixo, comissão alta | ~20% | |
| Varejo físico | Alcance, toque no produto | Margem do varejista (30–50%), prazo de pagamento | | |
| Venda direta / B2B | Volume por pedido | Ciclo longo | | |
| Financiamento coletivo | Pré-venda, validação | Esforço de campanha, prazo | 5–13% | |
